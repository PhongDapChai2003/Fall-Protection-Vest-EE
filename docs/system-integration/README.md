# System Integration

Use this folder for information that connects the electrical subsystems together.

Keep these items here as the design develops:

- system and electrical block diagrams
- subsystem input/output list
- MCU, IMU, power, driver, and mechanical interface notes
- connector and pin-assignment records
- integration checklists and test results
- open interface problems and assigned owners

Record final component choices and the reasons for them in [`../decisions/`](../decisions/).
